# Try MoneyMoney in three minutes after setup

This is a synthetic developer demo, not a place for your real financial records.
The first dependency install can take longer than the walkthrough.

1. Follow the [one-terminal setup](../clarity/README.md). Check that the banner says **Synthetic demo**.
2. Select **Show amounts**. Open **Holdings**, select an account and open a holding. Can you tell whose account it is, the currency, and where its value came from?
3. Look at the chart and its dates. Does the difference between a change in balance and a return make sense?
4. Try the Comfort view. Its design is unfinished: some headline totals still cover the whole portfolio. Tell us which words or controls confused you.
5. Stop with Ctrl-C. If you added invented manual records, restarting should retain them. Do not add your actual holdings.

[Report your first run](https://github.com/St-Gonne/moneymoney/issues/new?template=first-run.yml).
A failed install, one confusing screen or a confirmed successful run is enough. Include your OS, versions and commit; remove tokens, private values and local usernames.

Want a small code change? Start with [mobile holdings/filter usability](https://github.com/St-Gonne/moneymoney/issues/7).
For design, [Comfort account scope](https://github.com/St-Gonne/moneymoney/issues/5) is a useful bounded problem.
